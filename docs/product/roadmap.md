Status: In progress

## M1. Identity, Discovery, And Community Access

- email verification and sessions
- Organization selection and canonical search
- global membership/discovery Home
- Community visibility
- join-request persistence and Admin review
- exact-email existing-member add
- unique email-bound Mentor/Mentee invitations
- cross-organization explicit Admin invite/add
- CommunityMembership and role persistence
- user-facing Community Admin/community creation path
- define Backend verification mechanism for community creators

## M2. Profiles And Matching

- Mentor and Mentee onboarding persistence
- resolve global vs community-specific matching-preference scope
- current priorities and Mentor offerings/non-offerings
- community-scoped candidate generation
- relevance-first ranking
- up-to-three visible recommendation window
- Not-a-fit, next-set, and replacement state
- low-supply state

## M3. Ask And Coordination

- community-scoped Asks
- 48-hour response lifecycle and late response
- decline/expiry replacement integration
- Calendly/LinkedIn accepted-Ask handoff
- LinkedIn outreach confirmation
- Calendly lightweight Scheduled UX state
- existing private conversation follow-up

## M4. Beta Hardening

- transactional notifications
- audit history and retries
- authorization/privacy tests
- community-boundary tests
- join-request/Admin projection tests
- staging validation and beta runbook
- instrument recommendation coverage (3/2/1/0), Not-a-fit, Ask send, and replacement availability

## Research / Experimentation

- simulate Mentor pools of different sizes and thematic concentration
- validate minimum viable Mentor-pool/readiness hypothesis
- test global vs community-specific Mentee/Mentor matching preferences
- test whether aggregate Mentor-offering visibility helps low-supply UX

## Post-MVP Candidates

- cross-community Mentor discovery, only if explicitly designed
- Community Admin analytics/supply dashboards
- institutional SSO/roster integration
- verified completion/credentials/badges
- richer creator authority/official-community controls where needed
